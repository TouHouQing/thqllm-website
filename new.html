02 / CAPABILITIES

从想法与素材，到可交付的成片

把分镜、参考素材、生成任务和成片导出放在一个创作流程中，按需使用 AI 辅助。

FEATURE 01

文本与图片

直接输入文本、上传图片，也可配置自己的服务 URL 和 Key，生成提示词、图片，或基于参考图编辑图片。

FEATURE 02

分镜与画布

按镜头组织脚本、首帧和视频，用可视化连线串起创作步骤。

FEATURE 03

角色与场景参考

建立角色、场景与风格卡片，复用描述和参考图，并锁定需要保持的素材版本。

FEATURE 04

视频生成与续创

选择本站视频分组和模型，使用提示词、首帧或视频参考继续创作镜头。

FEATURE 05

版本与任务管理

跟踪生成状态，预览并选择镜头版本，保留已有结果再尝试新的创作方向。

FEATURE 06

MP4 成片导出

按分镜顺序裁剪、调整转场和音频，在浏览器本地拼接成片；项目也可导出 ZIP 备份。

开发者三步接入 API

浏览器创作可直接进入工作台；开发者创建 API Key 后提交视频任务，再查询状态与下载结果。 以下为基础请求示例，请将模型 ID 和参数替换为当前账号可用配置。

  1. 注册 THQ Video API 账号 登录 new.thqllm.com 控制台并完成账号创建。
  2. 创建视频 API Key 为不同应用或环境分配独立的调用密钥。
  3. 提交任务并轮询 保存任务 ID，查询完成状态后获取视频结果。

05 / FAQ

关于 AI 视频创作与 API

了解创作方式、模型选择和项目保存；具体模型参数请以控制台为准。

THQ Video API 支持哪些视频模型？

按本站账号可用分组选择视频模型。模型名称、参数与价格会随渠道调整，以控制台当前模型广场为准。

视频 API 的 Base URL 是什么？

控制台和 API 基址均为 https://new.thqllm.com，视频任务接口从 /v1 开始，例如 POST /v1/videos。

文本与图片必须调用模型吗？

可以直接输入文本或上传图片，不调用对应模型。需要 AI 辅助时，每位用户可配置自己的文本或图片服务 URL 和 Key。

视频模型如何计费？

视频模型价格以控制台模型广场和任务记录为准。

项目和素材保存在哪里？

项目、画布与已保存素材在当前浏览器中保存，可导出 ZIP 备份并在其他设备导入继续创作。暂不提供项目自动跨设备同步。

遇到生成失败应该怎么处理？

先停止轮询并记录脱敏后的错误信息，确认模型权限、余额和请求参数后再重试。 已确认失败的任务按平台规则处理退款。
