# 关于 THQLLM

THQLLM 是 THQ 围绕 LLM API 实际使用场景延伸出的产品集合，覆盖 AI 大模型 API、AI 大模型中转站、AI 中转站、AI 编程、知识管理、图像创作和 AI 视频创作。
它关注的不只是模型调用本身，也关注模型如何进入日常开发、团队协作和个人工作流。

THQ 持续记录技术实践与个人项目。博客：[tohoqing.com](https://tohoqing.com/)；GitHub：[touhouqing](https://github.com/touhouqing)。

## 当前产品

### THQ API

THQ API 是 THQLLM 的 AI 大模型中转站和企业级 API 网关，提供 Codex 中转站、GPT 中转站、Claude 中转站以及 Gemini、Grok 和图像生成模型接入。
它服务于 AI 编程、自动化调用和各类兼容客户端，支持以统一的账户、API Key 和工具配置流程连接常用模型能力。

对于 AI 代充、GPT 代充、Claude 代充等账户服务，请以 THQ API 控制台展示的官方入口、价格和使用规则为准。

项目地址：[sub.thqllm.com](https://sub.thqllm.com/)

### THQ Video API

THQ Video API 在 `new.thqllm.com` 提供 AI 视频创作工作台与视频模型 API 服务。
创作者可以用分镜表和画布串联文本、图片、视频，复用角色、场景与风格参考，选择镜头版本，
再按顺序拼接导出 MP4，适合短视频、产品展示和 AI 短剧的创作流程。

文本可以手动输入，图片可以直接上传，也可以使用每位用户自行配置的文本或图片服务生成。
视频使用本站账号可用的分组与模型；开发者可通过 API 接入自己的应用和自动化工作流。
可用模型、参数与价格以控制台当前展示为准。

项目地址：[new.thqllm.com](https://new.thqllm.com/)

### FluctGraph

FluctGraph 面向 AI IDE、Agent 与知识库工作流，提供私有知识图谱接入层。它用于把资料、上下文和工具链更有条理地连接到 AI 工作流中。

项目地址：[graph.thqllm.com](https://graph.thqllm.com/)

### THQ Switch

THQ Switch 是 `sub.thqllm.com` 的专属桌面客户端。它把登录注册、余额与用量、API Key 管理、模型映射和本地工具配置整合到一个界面中，帮助用户减少手动修改 JSON、TOML 和环境变量的步骤。

下载地址：[GitHub Releases](https://github.com/TouHouQing/sub-switch/releases)

### Toho Image Studio

Toho Image Studio 是面向图像生成与编辑工作流的浏览器创作空间，用于组织提示词、生成与编辑相关的日常操作。

项目地址：[img.thqllm.com](https://img.thqllm.com/)

## 未来方向

THQLLM 会继续沿着实际使用场景完善产品：

- 让模型接入、客户端配置和账户管理更直接、更少出错。
- 为 AI 编程、Agent 与知识管理提供更连贯的工具协作方式。
- 持续扩展图像生成、编辑与创作工作流。
- 完善从分镜、素材参考、视频生成到成片导出的 AI 视频创作流程。
- 把可复用的经验整理为清晰的使用文档和工具能力。
