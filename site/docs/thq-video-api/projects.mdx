# 素材管理与成片导出

## 项目与素材库

项目包含分镜、节点、连线、已保存素材和创作设置。素材库用于组织图片、视频以及角色、场景、风格卡片。
给素材取清晰名称，把同一角色或场景的参考集中到卡片中，再应用到分镜。
图片生成、参考图编辑和镜头生成的历史版本可以帮助你比较结果，保留满意版本继续使用。

## 本地合成 MP4

1. 完成需要使用的视频镜头，选择各镜头的版本。
2. 按分镜顺序把镜头加入本地合成，检查片段顺序。
3. 按需要设置裁剪范围、转场和音频。
4. 预览后导出 MP4，检查画面、声音与时长。

本地合成在浏览器中使用已有片段，不会额外调用视频模型。导出期间保持页面打开，较多或较长素材会占用更多内存和处理时间。
遇到素材无法读取，先检查该镜头能否预览、下载，修复或重新导入素材后再导出。

## AI 续创最终视频

选择完成镜头作为参考，填写最终视频的提示词和参数，再选择本站视频分组与模型提交。
这是一次新的模型生成，按渠道规则计费；模型可能重新组织参考镜头。
要求按顺序保留原镜头时，使用本地合成 MP4。

## 项目 ZIP 备份

在项目操作中导出 ZIP 备份，保存到自己的文件夹。重要生成结果也建议单独下载。
在另一台设备打开工作台并导入 ZIP，确认素材可用、节点与连线完整后继续创作。
普通项目配置导出与包含素材的 ZIP 备份用途不同，转移设备时优先使用项目 ZIP。

## 数据保存在哪里

| 内容 | 保存方式 |
| --- | --- |
| 文本与图片服务 URL、API Key | 按登录用户在服务器保存，Key 加密存储 |
| 项目、分镜、画布、卡片、已保存素材 | 当前浏览器的本地存储 |
| 视频计费任务与查询状态 | 本站服务的任务记录 |
| 导出的 MP4 或 ZIP | 你下载保存的位置 |

项目与素材目前不自动跨设备同步。清理站点数据、使用无痕窗口、切换浏览器或设备前，先备份项目和重要素材。
生成结果的远程下载地址可能有有效期，及时下载并保存。
