# 生成第一条视频

先用一个镜头跑通流程，再扩展成多镜头内容。文本和图片都可以直接输入，第一次使用无需先配置外接模型。

<ProjectLink href="https://new.thqllm.com/studio">打开创作工作台</ProjectLink>

## 1. 登录并新建项目

登录 `new.thqllm.com`，进入“创作工作台”，创建项目并命名。
在“分镜表”中新增一个镜头；需要自由连接素材时切换到“画布”。

## 2. 准备文本与图片

直接填写画面和动作，例如：“雨后的街道，一位穿白色外套的女性向镜头走来，镜头缓慢后退，柔和自然光。”
纯文本生成视频可以暂时不加图片。有角色、产品图或首帧时，上传到图片节点，选用“上传图片”的方式。

需要 AI 辅助时，打开“文本与图片服务”，分别填写自己的 URL 与 Key，保存并获取模型，再选择用于文本或图片生成的模型。
具体步骤见[文本、图片与外接服务](/docs/thq-video-api/text-images)。

## 3. 连接输入并选择视频模型

在画布中，将文本输出接到视频节点的输入；有图片时把图片接到视频节点。
普通连接会按素材类型传递输入。“高级连接”用于区分首帧、参考图、参考视频和视频延长等用途。

先选择“视频分组”，再点击模型选择按钮。在弹窗中查看模型名称、描述与价格，选定具体模型。
当前有 Seedance 2.0、Seedance 2.5 与 MiniMax-H3 相关渠道，实际列表取决于你的账号与分组。

时长、分辨率、比例和参考素材数量请按所选模型的当前说明填写。
名称相近的两个渠道也可能有不同参数，不要套用旧教程的固定限制。

## 4. 检查并生成

点击“开始生成”，检查提示词、参考素材、参数和预计费用，再确认提交。
连接的前置节点会参与执行；手动文本和上传图片直接作为输入，选用模型的节点会先生成结果。

查看节点状态和任务记录，完成后预览视频。需要重做时保留已有结果再生成新版本，选定要使用的镜头版本。
请求超时或状态不明时先查询现有任务，避免连续点击创建重复计费任务。

## 5. 保存结果与成片

单镜头可以直接预览、下载。多镜头内容按分镜顺序加入本地合成，裁剪片段并调整转场、音频后导出 MP4。
本地合成使用已有视频；“AI 续创最终视频”会另外提交一次模型生成任务。

项目保存在当前浏览器。完成一个阶段后导出项目 ZIP 备份；换设备时导入 ZIP，再继续创作。
更多操作见[素材管理与成片导出](/docs/thq-video-api/projects)。
