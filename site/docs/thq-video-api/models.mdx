# 视频分组与模型选择

## 先选择分组，再选择模型

视频工作台使用本站账号的可用分组。先选择“视频分组”，再打开模型选择弹窗，查看模型名称、描述和价格。
API 调用则使用 API Key 所配置的分组与模型权限，工作台选中的分组不会自动改写你的 API Key。

## 当前模型体系

下表以 **2026 年 10 月 25 日**本站公开模型目录为例，帮助识别当前渠道，不是长期固定的模型名单。
登录后的权限与所选分组可能使你看到的列表不同。

| 模型体系 | 当前目录中的名称示例 | 选择时检查 |
| --- | --- | --- |
| Seedance 2.0 | `at2-seedance-2.0-720p`、`sd4-seedance2.0-720p`、`sd4-seedance2.0-1080p` | 分辨率、时长、图片视频音频参考支持、计费方式 |
| Seedance 2.0 fast / mini 渠道 | `sd4-seedance2.0fast-720p`、`sd4-seedance2.0mini-720p` | 具体渠道说明，不要只根据 fast 或 mini 名称推断能力 |
| Seedance 2.5 | `sd4-seedance2.5-720p`、`sd4-seedance2.5-1080p`、`at2-seedance-2.5-480p` | 时长、素材数量、提示词和参考视频支持 |
| 特价与固定配置渠道 | `特价seedance-2.0-720p`、`特价seedance-2.5-720p` | 是否固定时长、固定价格，以及参考素材限制 |
| MiniMax H3 | `MiniMax-H3` | 当前渠道的分辨率、时长、参考图片和视频支持 |

站点会调整别名、渠道和模型映射，提交请求时使用当前列表中的完整模型 ID。
旧教程里的模型 ID 不代表当前分组仍然可用。

## 模型能力与参考输入

| 场景 | 推荐输入 | 需要确认 |
| --- | --- | --- |
| 文生视频 | `prompt` 与模型支持的时长、画幅、清晰度 | 模型是否支持纯文本生成与所选参数 |
| 单图或多图参考 | JSON `images` URL 数组 | 图片数量、顺序、参考用途和格式限制 |
| Seedance 多模态参考 | 按模型添加 `reference_videos` / `reference_audios` | 不是所有同系列渠道都支持音视频参考 |
| 单张本地参考图 | 一个 multipart `input_reference` 文件字段 | 模型是否支持文件输入以及文件大小限制 |
| 固定时长或固定配置 | 模型说明要求的参数 | 不套用其他渠道的时长、分辨率和参考素材组合 |

参考音频不等于输出一定带音轨，参考视频不等于自动支持视频延长。
输入方式和素材可访问性见[参考图片、视频与音频](/docs/thq-video-api/media)。

## API 获取可用模型

使用准备调用视频的 API Key 请求：

```bash
curl -fsS https://new.thqllm.com/v1/models \
  -H "Authorization: Bearer $THQ_VIDEO_API_KEY"
```

在返回的 `data` 列表中复制模型 `id`，再用于视频请求的 `model` 字段。
模型列表用于确认可见 ID，参考素材、价格和具体参数仍需查看该渠道说明。
创建 Key 时选择正确分组，并确认模型限制没有排除目标模型。

## 参数以渠道说明为准

时长、分辨率、比例和参考素材数量不按某个别名统一限制。
同属 Seedance 的渠道也可能分别支持自由时长、固定时长或不同素材组合。
例如固定 30 秒的渠道不能直接套用其他渠道的 5 秒请求。

工作台允许填写参数，并自动组织媒体请求格式；这不代表任何上游都接受所有参数。
API 中用字符串 `seconds` 表示时长，`size` 表示比例，`resolution` 表示独立清晰度；不把比例换算为像素尺寸。
完整字段与兼容别名见[请求参数](/docs/thq-video-api/parameters)。
不确定时先使用该渠道支持的最小文本请求，再增加首帧、参考图或视频。
需要保存常用设置时，使用视频提交模板；渠道调整后检查模板中的模型、分组和参数是否仍适用。

## 价格与计费

查看模型弹窗或模型广场中的当前价格与说明，提交前核对费用预览。
模型可能按请求、时长或其他规则计费，实际金额取决于当前渠道、分组和提交参数。
本教程不维护固定单价表，实际扣费以本站任务与使用记录为准。

文本和图片使用你配置的服务，相关费用由该服务计算。手动文本、上传图片与本地合成 MP4 不调用对应模型。

## 看不到模型或分组

先确认账号可用分组和 API Key 分组；在工作台重新选择分组并刷新列表。
不要用管理后台里的渠道模型列表替代当前用户的可调用模型列表。
模型在目录中存在，但没有当前分组权限、可用渠道或对应 Key 权限时，仍不能调用。
继续查看[视频 API 接入教程](/docs/thq-video-api/video-api)或[常见问题](/docs/thq-video-api/faq)。
