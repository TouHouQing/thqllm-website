# 分镜、画布与镜头续创

## 分镜表：先安排镜头

一个分镜对应一个镜头的创作内容。先安排镜头顺序、画面、动作和参考素材，再逐个确认生成结果。
用统一的角色、场景与风格描述，让相邻镜头的创作方向保持一致。
AI 分镜草稿需要检查后再应用，避免把尚未确认的剧情直接送去生成。

## 画布：连接创作步骤

| 连接 | 用途 |
| --- | --- |
| 文本 → 图片 | 用整理后的描述生成画面或首帧 |
| 文本 → 视频 | 提供视频画面和运动提示词 |
| 图片 → 图片 | 基于已有图片或上传图片编辑 |
| 图片 → 视频 | 提供首帧或参考图 |
| 视频 → 视频 | 以完成镜头作为参考，或延长视频；取决于模型能力 |

从源节点的输出点连接到目标节点的输入点。普通输入按素材类型组织数据；
只有需要指定首帧、参考图、参考视频或视频延长时，才打开“高级连接”。

## 前置节点怎样执行

开始生成下游视频时，连接的前置节点会参与执行。手动文本与上传图片直接传递；
需要模型生成的节点先准备结果，再进入视频提交。
前置节点失败时，先修复该节点，不要重复点击下游视频生成。

已有可用结果时，先选择要使用的版本。修改文本、图片或连接后检查输入预览，确认下游使用的是你希望的素材。

## 角色、场景与风格卡片

在素材库中建立角色、场景或风格卡片，填写名称、描述和参考图。
将卡片应用到指定分镜或全部分镜，减少每个镜头重复输入。

卡片提供创作参考，最终人物、场景和风格效果仍取决于素材与所选模型。
需要保持同一角色时，使用相同的参考图片，并锁定适合的图片版本。

## 挑选镜头版本

重复生成会产生多个版本。预览后选择当前使用的版本，再将它加入后续参考或成片。
锁定连接版本后，该连接继续使用指定结果；取消锁定后再切换到其他结果。
上游结果改变时，检查后续镜头的引用，避免误用之前的素材。

## 接续下一个镜头

需要延续画面时，可以从完成视频提取末帧，作为下一镜头的首帧。
需要参考动作或运镜时，将完成视频连接到下一视频节点，选择参考视频用途。
视频延长是另一种模型能力，只有所选渠道支持时才使用对应输入。

## 最终视频怎么做

按顺序成片时使用本地合成，明确选定镜头版本、裁剪区间、转场和音频。
需要模型重新创作最终视频时，选择参考镜头并使用“AI 续创最终视频”；它会生成一个新视频，不能保证逐帧保留原片段，且会新增计费任务。
具体操作见[素材管理与成片导出](/docs/thq-video-api/projects)。
