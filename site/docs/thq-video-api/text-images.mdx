# 文本、图片与外接服务

文本与图像创作在 THQ Video API 工作台中完成。你可以只准备素材，也可以将结果连接到视频节点继续生成。

## 手动文本：直接传递想法

新增文本节点，在模型选项中选择“手动输入（不调用模型）”，填写脚本、画面或运动描述。
连接下游节点后，输入内容会作为文本参考传递，不请求文本模型，也不产生文本服务费用。
文本建议写明主体、场景、动作、构图和风格。已有完整视频提示词时，可以直接填写到视频节点。

## 上传图片：直接使用已有素材

图片节点可以上传 PNG、JPEG、WebP 图片，不必先调用图片模型。
选定图片后，可连接到视频节点作为首帧或参考图，也可加入角色、场景、风格素材卡片。
工作台接收的文件大小与图片尺寸仍有限制，上传时以页面提示为准。

## 配置自己的文本与图片服务

1. 打开“文本与图片服务”，切换“文本”或“图片”。
2. 填写完整的 HTTPS API 基址与自己的 API Key，例如 `https://sub.thqllm.com/v1`。
3. 点击“保存并获取模型”，选择该服务返回的模型。
4. 在对应节点选择模型，填写提示词，再开始生成。

文本和图片可以来自两个不同服务。配置属于当前登录用户，Key 在服务器加密保存，不是管理员替所有用户配置同一把 Key。
已有 Key 时，留空 Key 字段可保留原密钥；更换服务或密钥后重新获取模型列表。

基址应包含服务的 API 前缀，例如 `/v1`，不要填写具体的 `/chat/completions` 或 `/images/generations` 路径。
当前外接服务使用 OpenAI 兼容接口：模型列表 `/models`、文本 `/chat/completions`、图片生成 `/images/generations`、参考图编辑 `/images/edits`。
服务能列出模型不等于每个模型都支持所有这些接口，仍需选择与用途匹配的模型。

## 用文本模型整理创作内容

将想法交给文本节点，生成画面描述、生图提示词和视频运动提示词，确认并编辑结果后再传给下游。
分镜规划可以先产出草稿，检查镜头顺序、人物和动作，再应用到项目。

如果结果出现“查看工作区”“请告诉我风格”等闲聊或工具回复，先检查文本服务返回与所选模型。
选择能通过该服务输出普通文本的模型，并在结果编辑区确认真正用于创作的内容。

## 生成图片与首帧

选择图片模型，描述主体、场景、风格与构图。需要角色或场景一致性时，使用素材卡片里的描述和参考图。
图片生成后检查人物、产品、构图和关键细节，挑选合适的结果再连接视频。
图片节点可以独立生成素材，项目不要求每张图片都立即转换成视频。

## 使用参考图编辑图片

将上传图片或已有图片结果连接到新的图片节点，填写修改要求，例如：“保留人物与服装，把背景改成傍晚街道。”
选择支持图像编辑的外接图片模型，生成新的图片版本，检查结果后再决定是否替换下游参考。

带参考图时会使用图片服务的编辑接口。多图编辑、输入数量与具体效果由外接模型决定；服务不支持时，改用一个参考图或换支持该能力的模型。

## 选择版本并传给视频

保留满意的图片版本，选中后连接到视频节点。需要稳定参考时，锁定连接使用的版本，避免切换图片结果后影响后续镜头。
首帧用于决定视频开头的画面，参考图用于提供人物、物品或场景信息；在“高级连接”中按需要指定用途。
视频参数与参考素材支持以[所选视频模型](/docs/thq-video-api/models)为准，工作台会自动组织媒体请求格式。

## 保存与备份

外接服务 URL 与 Key 随登录账号保存；图片、节点和项目在当前浏览器中保存。
需要换设备或清理浏览器时，先导出项目 ZIP，确认素材也已经备份。
相关操作见[素材管理与成片导出](/docs/thq-video-api/projects)。
