# THQ Video API

THQ Video API 在 `new.thqllm.com` 提供 **文本、图像与 AI 视频创作工作台，以及视频模型 API 服务**。
提示词组织、图片生成、参考图编辑、历史版本选择与视频创作统一在同一个工作台中完成。
创作者可以在浏览器中从想法、分镜和参考素材开始，生成镜头并导出成片；
开发者可以通过 API 把视频生成接入自己的产品和自动化工作流。

## 两种使用方式

| 使用方式 | 适合的场景 |
| --- | --- |
| 分镜表与画布创作 | 短视频、产品展示、AI 短剧与多镜头内容，直接组织素材和生成结果 |
| 文本与图像创作 | 手动准备素材，或生成提示词、图片与首帧，基于参考图编辑并选择结果 |
| 视频模型 API | 自有应用、后端服务、脚本和自动化视频生产流程 |

两种方式使用同一个本站账号体系。视频生成使用账号当前可用的模型分组，
模型名称、参数、参考素材支持、价格和实际扣费以控制台与对应渠道说明为准。

## 从想法到成片

1. **准备文本与分镜**：手动填写脚本和提示词，或使用自行配置的文本模型生成分镜草稿；确认后再进入下一步。
2. **准备图片**：直接上传已有图片，或调用自行配置的图片服务生成首帧、参考图，基于已有参考图编辑图片。
3. **组织创作素材**：建立角色、场景与风格卡片，将名称、描述和参考图应用到指定分镜或全部分镜；需要固定参考时可锁定版本。
4. **生成视频镜头**：选择本站视频分组和具体模型，填写提示词、时长、分辨率等参数，检查请求后提交；任务状态和生成结果可以继续查看。
5. **挑选与续创**：查看镜头的多个生成版本，选择合适的结果；也可使用前一镜头的末帧或视频参考继续创作。
6. **导出成片**：按分镜顺序裁剪、调整转场和音频，在浏览器本地拼接导出 MP4。

**文本和图片都可以不调用模型。** 手动文本与上传图片可以直接作为下游视频的输入。
需要 AI 辅助时，每位用户可在“文本与图片服务”中设置自己的服务 URL 和 API Key，并获取可用模型。
视频模型始终从本站账号可用的分组与模型中选择。

“本地合成 MP4”按顺序拼接已有镜头；“AI 续创最终视频”会将选定镜头作为参考，
再次调用本站视频模型生成一个新视频，并产生新的计费任务。

## 项目与备份

项目、画布和已保存素材存放在当前浏览器。建议使用项目 ZIP 导出备份，
在另一台设备上导入后继续创作；目前不提供项目的自动跨设备同步。

## 开发者 API 接入

控制台为 `https://new.thqllm.com`，API 基址为 `https://new.thqllm.com/v1`。先登录控制台，创建用于应用调用的 API Key，
确认当前账号可用的分组、模型与接口说明，再提交视频任务、保存任务 ID、查询状态并下载结果。

API 调用使用 Bearer API Key：

```http
Authorization: Bearer YOUR_THQ_VIDEO_API_KEY
```

建议在可信的后端服务、本地开发环境或受控脚本中保存 Key。不要把真实 Key 写入前端网页、
公开仓库、日志、截图或提交给第三方的排查信息。
