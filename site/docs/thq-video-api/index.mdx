# THQ Video API

THQ Video API 是 THQLLM 面向视频生成场景提供的 API 中转服务。
你只需要准备一个 API Key，提交视频任务，等待任务完成，再下载生成结果。
服务地址统一是 `new.thqllm.com`，不需要填写其他源站地址。

<ProjectLink href="https://new.thqllm.com/">打开 THQ Video API 控制台</ProjectLink>

## 第一次使用：照着 5 步完成

不需要先理解所有参数，按下面顺序就能生成第一条视频：

1. 在 [THQ Video API 控制台](https://new.thqllm.com/)注册或登录。
2. 创建一个 API Key，并复制保存。
3. 选择下方合适的模型分组，打开对应教程并复制“第一次调用”中的命令。
4. 提交任务后保存任务 ID，并查询到状态变成 `completed`。
5. 使用教程中的下载命令保存视频。

## 先选一个分组

如果你不确定要看哪篇教程，先按下面方式选择：

| 分组 | 适合场景 | 教程 |
| --- | --- | --- |
| SD2 | 通用文生视频、图生视频、分镜、multipart 文件上传 | [SD2 接入教程](/docs/thq-video-api/firefly-video-v2) |
| SD2 官方满血 | 官方 Seedance 2.0 0826，固定 15 秒，模型名自带 480p / 720p 分辨率 | [SD2 官方满血教程](/docs/thq-video-api/sd2-official) |

## SD2 常用模型

如果你还不知道选哪个，第一次直接使用 `firefly-video-v2-fast`，并选择 5 秒、720p。
这套参数适合先确认 API Key、账户和调用流程是否正常。

| 模型 | 适合场景 | 分辨率 | 时长 |
| --- | --- | --- | --- |
| `firefly-video-v2` | 画质优先，需要 1080p | 480p / 720p / 1080p | 5 / 10 / 15 秒 |
| `firefly-video-v2-fast` | 先测试效果，速度和成本优先 | 480p / 720p | 5 / 10 / 15 秒 |
| `leonardo-seedance-2.0` | Leonardo Seedance 2.0 标准速度 | 480p / 720p | 5 / 10 / 14 秒 |
| `leonardo-seedance-2.0-fast` | Leonardo Seedance 2.0 速度优先 | 480p / 720p | 5 / 10 / 14 秒 |

只需要记住：

- 想要最高输出规格，选择 `firefly-video-v2`。
- 想先快速跑通，选择 `firefly-video-v2-fast`。
- 想使用 Leonardo Seedance 2.0，选择以 `leonardo-seedance-2.0` 开头的模型。
- 所有模型都使用同一套接口格式，只需要替换 `model` 参数。

## SD2 官方满血模型

官方满血分组固定生成 15 秒视频，分辨率写在模型名里，不要再额外传 `resolution`。
这个分组的教程请看 [SD2 官方满血](/docs/thq-video-api/sd2-official)。

| 模型 | 适合场景 | 单价 |
| --- | --- | ---: |
| `seedance-2.0-0826-480p` | 标准质量，480p | 0.25 / 秒 |
| `seedance-2.0-0826-720p` | 标准质量，720p | 0.35 / 秒 |
| `seedance-2.0-fast-0826-480p` | 快速生成，480p | 0.20 / 秒 |
| `seedance-2.0-fast-0826-720p` | 快速生成，720p | 0.30 / 秒 |

## 专用服务地址

| 用途 | 地址 |
| --- | --- |
| 控制台与账号入口 | `https://new.thqllm.com` |
| API 基址 | `https://new.thqllm.com/v1` |
| 模型列表 | `GET https://new.thqllm.com/v1/models` |
| 创建视频任务 | `POST https://new.thqllm.com/v1/videos` |
| 查询视频任务 | `GET https://new.thqllm.com/v1/videos/{task_id}` |
| 下载生成结果 | `GET https://new.thqllm.com/v1/videos/{task_id}/content` |

调用接口时，完整地址就是“API 基址 + 接口路径”。例如创建任务：
`https://new.thqllm.com/v1/videos`。

## 你需要准备什么

只需要两个东西：

- THQ Video API Key
- 一个视频提示词 `prompt`

有参考图片、视频或音频时，再使用 `multipart/form-data` 上传素材。

## 认证方式

所有请求都需要携带 Bearer API Key：

```http
Authorization: Bearer YOUR_THQ_VIDEO_API_KEY
```

模型列表、账户余额和实际扣费以 [THQ Video API 控制台](https://new.thqllm.com/)当前显示为准。
建议只在后端、本地开发环境或受控脚本中保存 API Key，不要把真实 Key 放进公开前端代码。
